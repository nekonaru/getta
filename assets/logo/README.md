# Getta logo kit

Source files for the Getta identity. Getta is the winged herald of swift
delivery in spirit only; the mark is original geometry built from one
lowercase `g` and a single forward swoosh.

## Files

| File | Use |
|------|-----|
| `getta-symbol.svg` | Primary symbol, one colour, transparent background |
| `getta-symbol-reversed.svg` | Symbol reversed for dark backgrounds |
| `getta-horizontal.svg` / `getta-horizontal-reversed.svg` | Lockup, symbol left of the wordmark |
| `getta-stacked.svg` | Stacked lockup, symbol above the wordmark |
| `getta-black.svg`, `getta-white.svg` | One-colour black and reversed white exports |
| `getta-mono-00c896.svg`, `getta-mono-0f2420.svg` | One-colour mint and spruce exports |
| `getta-square.svg` | Symbol centred on a square canvas, avatars and social |
| `getta-app-icon.svg` | Symbol in mint on a spruce rounded tile |
| `getta-favicon.svg` | Tight square mark for browser tabs |
| `site.webmanifest` | Web app manifest fragment for favicons |

Wordmark lockups set `getta` in Fraunces Black (900). Convert text to outlines
before using the lockups in print; Fontsource provides the font files named
`fraunces-latin-900-normal.woff2`.

## Palette

| Token | Hex | Role |
|-------|-----|------|
| Spruce | `#0F2420` | Brand base, app icon tile, dark surfaces |
| Mint | `#00C896` | Primary action, glyph on spruce |
| Paper | `#F5F7F6` | Light background, symbol on spruce |
| Ink | `#111111` | One-colour symbol on light backgrounds |

## Clear space and minimum sizes

- Clear space: half the symbol height on every side.
- Do not recolour the symbol outside the palette.
- Minimum size: 16 px. Do not add detail below that.
- Never set the wordmark in another typeface.
- Never rotate, skew or restretch the mark.
